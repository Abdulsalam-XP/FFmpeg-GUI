NOTE FOR WHOEVER PUBLISHES THIS RELEASE
---------------------------------------
Because the bundled FFmpeg is a GPL build, distributing this zip means
distributing GPL-licensed binaries. If you would rather not take on those
obligations, swap bin/ffmpeg.exe and bin/ffprobe.exe for an LGPL build (the
same BtbN build server publishes "win64-lgpl" variants). The application does
not depend on any GPL-only feature; it uses libx264 for CPU compression, which
is itself GPL, so an LGPL FFmpeg build would need its own check that the
compression presets still work.
